# 简单画面升级

日期：2026-10-27。

## 范围

使用轻量的 Canvas 插画绘制，保留原生 JavaScript、无依赖和单文件运行方式。勇者增加脸部、头发、四肢、披风、剑盾，怪物增加可区分的身体和装备；背景增加草地纹理、石环与法阵。目标是轮廓清楚的简化人物，并非写实照片风格。

## 两个版本

- 默认新版，右上角按钮实时切换；localStorage 的 khVisualStyle 记住选择。
- 经典绘制分支保留原有画面。独立旧版快照位于 versions/keyboard-hero-classic.html，不进入构建覆盖流程。
- visuals.js 只负责装饰性绘制；game.js 仍控制战斗与词卡。build.py 将新脚本内联至 keyboard-hero.html，server.py 提供脚本访问。
- 绘制不调用 Math.random，不修改敌人、目标、进度或分数。视觉版本不影响成绩分组。

## 验证

- Python 10 项测试及 Node 玩法、词表解析测试通过。
- 两种画面绘制、八种怪物绘制及切换状态保持检查通过；测试将 Math.random 替换为抛错函数，确认绘制不影响游戏随机流。
- 经典快照与 e5a9553 中的单文件逐字节一致。
- 单文件构建、JavaScript 语法及 git diff --check 通过。
- 浏览器工具拒绝 file:// 本地文件预览；未完成浏览器视觉检查、不同屏幕尺寸的实际观感检查或完整试玩。
