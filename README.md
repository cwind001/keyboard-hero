# 键盘勇者 · Keyboard Hero

原生 JavaScript + Canvas 打字游戏，包含标准闯关、两分钟盲打练习、教材词库和 SQLite 本地成绩。

## 启动完整版本

需要 Python 3.9 或更新版本，无需安装第三方依赖：

```sh
python3 server.py
```

浏览器打开 <http://127.0.0.1:8765>。词库管理位于 <http://127.0.0.1:8765/library.html>。

- 每次开始前选择已有玩家或输入新昵称。同名昵称使用已有玩家，不设密码。
- 标准模式可选择内置词库，或合并多张教材词表；相同英文自动去重，不同释义合并显示。
- 设置会记住上次玩家、词表、每种怪物的提示配置和练习字母范围。
- 点击右上角「成绩」查看个人纪录、同条件排行榜和最近 20 局。打开成绩会暂停游戏，关闭后手动继续。
- 修改端口：`python3 server.py --port 9000`；使用其他数据库：`python3 server.py --db /path/to/game.db`。
- 服务仅监听本机 `127.0.0.1`；不提供网络账号、云同步或跨设备访问。

## 教材词库与拼写

在「词库管理」中创建教材（名称、版本、年级、册次）及单元词表。可编辑单条，也可批量粘贴，每行一条：

```text
apple 苹果
banana 香蕉
school 学校
```

支持空格或制表符分隔；先「校验与预览」再保存。修改文本中的整行可以编辑或移除单词。支持单词、带连字符的词和短语（例如 hard-working、ice cream）；英文最长 40 字符，允许字母、单词间空格和连字符，大小写统一为小写。重复词、数字、撇号及其他标点会明确报错。短语建议用制表符分隔中文释义。每张词表最多 3000 词。

中文释义最多 120 字；可先保存缺少中文的草稿。中文拼写玩法会要求补齐所选词汇的中文释义。教材或词表归档后不再出现在开局选项中，历史对局及其词汇快照保留。

开局选择简单、中等或困难，默认简单。提示按每个单词随机分配，与怪物种类无关；九头怪每个头分别抽取，精英与 Boss 每换一个新词重新抽取。选中、取消锁定或绘制不会改变已有提示。始终输入完整英文（包括提示的字母）。

| 难度 | 完整英文 | 中文＋首尾字母 | 纯中文＋长度 | 拼写挑战合计 |
| --- | --- | --- | --- | --- |
| 简单 | 92% | 6% | 2% | 8% |
| 中等 | 80% | 15% | 5% | 20% |
| 困难 | 60% | 30% | 10% | 40% |

这些是每个词的抽取概率，单局实际占比会浮动。难度只调整提示比例，原有出怪速度、数量和击退规则保持一致。选择会被记住，盲打练习始终显示单字母。

每个空位代表一个字母；空格和连字符会保留显示，但无需输入。例如 `ice cream` 输入 `icecream`，`hard-working` 输入 `hardworking`；空格键仍用于暂停。正确输入逐字高亮或填入。可点击怪物或九头怪的词卡明确选定目标；也可输入首字母自动锁定最近的匹配怪物，Esc 取消锁定。点击其他目标会重置当前输入进度。

自定义词库尽量将短词分配给普通怪、长词分配给重甲和多段怪；词库缺少某类长度时使用其中的其他词。小词表允许重复使用，不会混入内置单词。九头怪分三组展示词卡，每组 3 个，当前组全部完成后才展示下一组；每完成一个词就减少一个头，共完成 9 次。同一单词重复出现也逐头消灭。只有当前组可点击或通过首字母锁定。词卡跟随本体移动，通常在上方，靠近场地顶部时改为下方，避免遮挡本体。

## 已录入的课本词库

人教版英语五年级上册的照片词表已保存为 `wordbooks/pep-grade5-volume1.json`，核对记录见 [照片录入记录](docs/wordbooks/pep-grade5-volume1.md)。Unit 1–6 已根据照片及补图录入完整，共 119 个词条，均包含中文释义。

在另一份本地数据库中恢复这些词表：

```sh
python3 import_wordbook.py wordbooks/pep-grade5-volume1.json
```

导入复用同名教材和单元，只追加缺少的词条，保留已有释义，并且不会中断正在进行的游戏。词表 JSON 可随仓库保存，个人 SQLite 数据库仍不提交。

## 标准闯关

- 怪物四面逼近，输入完整单词自动攻击，无需回车。使用英文输入法，空格暂停。
- 中央玩家头顶显示五格生命。
- 普通：史莱姆、哥布林；快速：疾跑怪、飞行翼龙；重甲：钢铁守卫；精英：暗影法师；Boss：吸血蝙蝠、九头怪。
- 精英和 Boss 每完成一个单词，按场地比例击退约 50 像素并停顿 0.3 秒。
- 场上最多 9 只；快速最多 2 只，精英及 Boss 各 1 只，三类合计最多 3 只。
- Boss 在场时快速最多 1 只，普通出怪间隔 4.5 秒；两个 Boss 之间至少间隔 8 秒。
- 普通出怪在 4 分 30 秒停止并进入清场；两个 Boss 均已出场，且剩余怪物清完后立即通关，无需等到五分钟。出怪结束前的短暂无怪间隙，以及 Boss 尚在等待出场时，不会提前结算。

## 盲打练习

每轮两分钟，只出现一只慢速单字母史莱姆。屏幕键盘显示目标键及手指提示，可选择基准行、上排、下排或全部字母。结算显示准确率及每分钟正确字母数；成绩按字母范围分别统计。

## 数据与成绩

数据库自动创建在 `data/keyboard-hero.db`，不提交 Git。已有版本 1 数据库会自动升级到版本 2，保留原有成绩。备份时先停止服务，再复制该文件；恢复时停止服务并放回原路径。

- 开始时创建对局及词库快照，结束时保存分数、击杀、最高连击、输入次数、准确次数、时长和结果。
- 修改词库不会改变已创建对局。内容指纹包含英文和释义；改名不改变分组，修改内容会形成新分组。
- 排行榜仅统计已结算对局，按模式、词库来源、词汇内容、难度及提示比例及规则版本隔离。历史对局保存实际使用的提示配置。
- 个人纪录中的最佳准确率和最佳速度可能来自不同对局。
- 切换模式、离开页面会将当前对局记为中断；服务重启将遗留的进行中对局标为中断，不纳入排行。
- 保存失败会显示提示，并将待保存结果缓存在浏览器，恢复连接后重试；若服务已重启并把该局标为中断，则不会再改写为已结算。
- 昵称仅为本地身份区分，无鉴权；成绩由浏览器上报，不具备防作弊能力。

整体连接流程见 [系统架构](docs/architecture.md)，表结构与接口见 [数据库设计](docs/database.md)。

## 单文件离线版

也可以直接打开 `index.html` 或 `keyboard-hero.html`。离线模式使用内置词库，最高分存储于当前浏览器；数据库和教材管理需要通过本地服务使用；离线版也支持三个难度的随机提示。原有浏览器最高分不会自动归属到新玩家。

## 开发与检查

```sh
python3 build.py
node --check game.js
node --check app.js
node --check library.js
python3 -m unittest discover -s tests -v
node tests/game.test.js
node tests/library.test.js
```

- `game.js`：怪物、Canvas 绘制、键盘和点击交互。
- `app.js`：玩家、开局配置、对局保存和成绩界面。
- `library.html` / `library.js`：教材词库管理。
- `server.py` / `schema.sql`：本地接口及 SQLite 表结构。
- `vocabulary.json`：内置词条及中文释义；构建时同步到游戏源码。
- `build.py`：同步内置词库，并合并 HTML、CSS 和脚本生成 `keyboard-hero.html`。

自动检查覆盖数据库核心流程和玩法回归；完整闯关难度仍需人工持续试玩。
