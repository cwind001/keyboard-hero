# 键盘勇者 · Keyboard Hero

游戏一：浏览器打字生存游戏，包含标准闯关和盲打练习。

## 运行

直接用桌面浏览器打开 `index.html`，无需安装依赖。也可以打开自包含的 `keyboard-hero.html`。

请使用英文输入法。输入字母自动攻击，Esc 取消锁定，空格暂停。页面右上角切换模式。

## 玩法

- 标准闯关：怪物从四周逼近，输入头顶单词击杀，角色头顶显示五格生命。
- 慢速史莱姆与哥布林、快速疾跑怪与翼龙、重甲守卫、精英法师，以及吸血蝙蝠和九头怪。
- 精英和 Boss 每完成一个单词击退约 50 像素，并停顿 0.3 秒。
- 场上最多 9 只怪物；快速怪最多 2 只、精英和 Boss 各 1 只，三类合计最多 3 只。
- Boss 在场时快速怪最多 1 只，出怪间隔 4.5 秒。两个 Boss 之间至少间隔 8 秒。
- 五分钟后进入清场，击败剩余敌人通关。
- 盲打练习：两分钟一轮，单只慢速怪、单个字母，屏幕键盘和手指提示；可选择字母范围。

## 文件

- `index.html`：页面结构
- `style.css`：界面样式
- `game.js`：Canvas 绘制、游戏逻辑与键盘交互
- `keyboard-hero.html`：可以单独分发的完整游戏
- `build.py`：从三个源文件生成单文件版本

修改源码后运行 `python3 build.py`，同步单文件版本。

## 检查

`node --check game.js` 检查 JavaScript 语法。核心玩法经过模拟逻辑检查，难度和视觉表现需要持续试玩调校。

最高分仅存储于浏览器本地。
